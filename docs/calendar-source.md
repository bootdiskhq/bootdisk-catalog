# Calendar source binding

J.DTX calendar titles are accepted as source-documentation observations only
when the exact preserved bytes, inventory size/hash, source section, raw fields
and normalized title agree. A wrong section, modified raw title or changed
inventory hash fails. RTF prose retains the existing independent byte binding.

No software identity, version, distribution type or approval is inferred from
calendar membership or numeric Type. K-CD 16/2001 is a local intake trial; its
99 posts are not automatically published. Existing curator work is unchanged.
